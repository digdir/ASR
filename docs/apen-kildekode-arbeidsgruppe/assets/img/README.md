## Eksempel på bruk

Fra en underside, for eksempel `om-arbeidet/index.md`:

```html
<figure>
  <img src="../assets/img/tabler/brand-open-source.svg" alt="Ikon for åpen kildekode">
  <figcaption>Ikon: Tabler Icons, MIT-lisens.</figcaption>
</figure>
```
