# Repository Instructions

## Shared GitHub Workflow

This repository is shared by several collaborators with separate local clones.

Before making edits, always verify that the local branch is based on the latest
GitHub version:

1. Fetch or check `origin/main`.
2. If local `main` is behind, update it with a fast-forward pull before editing.
3. If there are local uncommitted changes, preserve them before updating and
   reapply them on top of the latest `origin/main`.
4. Before pushing, check that `origin/main` has not moved since the local update.
